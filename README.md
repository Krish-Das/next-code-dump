# NextJS 15 starting template (DEVELOPEMENT)

## Cloning:

```bash
git clone -b @next15-test https://github.com/Krish-Das/next-code-dump.git .
```

### single branch:

```bash
git clone -b @next15-test --single-branch https://github.com/Krish-Das/next-code-dump.git .
```

## Running locally

```bash
npm run dev
```
