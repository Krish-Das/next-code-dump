# Drag and drop using pdnd

[🎥 Watch demo video](./docs/demo.mp4)

## Cloning:

```sh
git clone -b pdnd/with-rac-atlaskit https://github.com/Krish-Das/next-code-dump.git --single-branch
```

## Running locally

```sh
npm run dev
```
